# Issue 提交规范

感谢您对本项目的关注和贡献！为了更好地管理和跟踪问题，请遵循以下 Issue 提交规范。

## Issue 类型

我们提供以下几种 Issue 模板：

### 1. Bug 反馈
- **用途**：当您发现了程序中的错误、异常或不符合预期的行为时使用
- **包含字段**：如何复现、预期结果、实际结果、截图、版本信息等
- **标签**：`bug`

### 2. 功能建议  
- **用途**：对本项目提出新的功能建议或改进想法时使用
- **包含字段**：相关问题描述、期望的解决方案、替代方案、附加信息等
- **标签**：`enhancement`

## 提交前须知

1. **搜索现有 Issue**：在提交前，请先搜索是否已有相同或类似的问题
2. **详细描述**：请尽可能详细地描述问题或建议，包括复现步骤、环境信息等
3. **清晰标题**：使用清晰、简明的标题概括您的 Issue
4. **必要信息**：请提供必要的环境信息和错误日志

## Issue 标签说明

- `bug`：程序错误或异常行为
- `enhancement`：功能建议或改进
- `documentation`：文档相关
- `good first issue`：适合新手贡献者
- `help wanted`：需要帮助解决的问题
- `duplicate`：重复的 Issue
- `invalid`：无效的问题
- `wontfix`：不会修复的问题
- `question`：疑问或讨论

## 如何提交 Issue

1. 点击 "New Issue" 按钮
2. 选择合适的 Issue 模板
3. 按照模板填写相关信息
4. 提交 Issue
